# 3교시: Supabase Python 클라이언트와 FastAPI 연동

**소요시간:** 90분 (이론 30분 + 실습 60분)  
**사전 지식:** 1~2교시(Supabase 설정, SQL Editor 실습), FastAPI 기초, Python 환경변수

---

## 학습 목표

- `supabase-py` 클라이언트를 초기화하고 연결을 확인한다
- `python-dotenv`로 `.env` 파일에서 API 키를 읽는다
- Python 메서드와 SQL 문법을 1:1로 대응시켜 이해한다
- INSERT, SELECT, 조건 조회를 Python 코드로 구현한다
- FastAPI 엔드포인트에서 Supabase 데이터를 저장하고 응답한다

---

> Python 클라이언트를 쓰면 SQL을 직접 작성하지 않고도 CRUD가 가능합니다. 하지만 복잡한 JOIN·집계나 RLS 정책 작성(7교시)은 결국 PostgreSQL SQL 지식이 필요하므로, 1~2교시에서 다진 SQL 기초가 계속 쓰입니다.

## 3. Supabase 클라이언트 초기화

```python
import os
from dotenv import load_dotenv
from supabase import create_client, Client

load_dotenv()

SUPABASE_URL = os.environ["SUPABASE_URL"]
SUPABASE_SERVICE_ROLE_KEY = os.environ["SUPABASE_SERVICE_ROLE_KEY"]

supabase: Client = create_client(SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY)
```

### 연결 확인

```python
# 간단한 조회로 연결 테스트
result = supabase.table("app_users").select("*").limit(1).execute()
print(result.data)  # [] 또는 데이터 리스트 출력되면 연결 성공
```

## 4. Python 클라이언트 vs SQL 비교

`supabase-py`는 SQL을 Python 메서드 체이닝으로 표현합니다.

| SQL 문법 | supabase-py 메서드 |
|----------|--------------------|
| `SELECT * FROM app_users` | `.table("app_users").select("*")` |
| `SELECT id, username FROM ...` | `.select("id, username")` |
| `WHERE id = 'xxx'` | `.eq("id", "xxx")` |
| `WHERE role != 'system'` | `.neq("role", "system")` |
| `ORDER BY created_at DESC` | `.order("created_at", desc=True)` |
| `ORDER BY created_at ASC` | `.order("created_at", desc=False)` |
| `LIMIT 10` | `.limit(10)` |
| `INSERT INTO ... VALUES (...)` | `.insert({...})` |
| `INSERT ... RETURNING *` | `.insert({...}).select("*")` |
| `UPDATE ... SET ... WHERE` | `.update({...}).eq("id", id)` |
| `DELETE FROM ... WHERE` | `.delete().eq("id", id)` |

마지막에 반드시 `.execute()`를 붙여야 실행됩니다.

```python
# execute() 없으면 실행 안 됨!
result = supabase.table("app_users").select("*").execute()
#                                                ↑ 반드시 필요
```

## 5. 데이터 조회

### 전체 조회

```python
result = supabase.table("app_users").select("*").execute()
users = result.data  # 딕셔너리 리스트
print(users)
# [{"id": "abc...", "username": "kim", "display_name": "김학생", ...}, ...]
```

### 정렬 + 특정 컬럼만

```python
result = (
    supabase.table("app_users")
    .select("id, username, created_at")
    .order("created_at", desc=True)
    .execute()
)
```

### 조건 조회 (.eq)

```python
result = (
    supabase.table("conversations")
    .select("*")
    .eq("user_id", "사용자-UUID")  # WHERE user_id = '...'
    .order("created_at", desc=True)
    .execute()
)
conversations = result.data
```

### 단건 조회 후 없으면 404

```python
result = (
    supabase.table("app_users")
    .select("*")
    .eq("id", user_id)
    .limit(1)
    .execute()
)

if not result.data:
    raise HTTPException(status_code=404, detail="사용자를 찾을 수 없습니다")

user = result.data[0]  # 딕셔너리 한 건
```

## 6. 데이터 저장

```python
# .insert(payload) — INSERT
# .select("*")    — RETURNING * (저장된 행 바로 반환)
result = (
    supabase.table("app_users")
    .insert({
        "username": "kim",
        "display_name": "김학생",
    })
    .select("*")
    .execute()
)
created_user = result.data[0]
```

### ⚠️ .select("*") 없으면 result.data가 빈 리스트

```python
# ❌ .select("*") 없으면 저장은 되지만 결과를 반환하지 않음
result = supabase.table("app_users").insert({"username": "kim", ...}).execute()
print(result.data)  # [] (빈 리스트)

# ✅ 저장된 데이터를 응답으로 반환하려면 .select("*") 필수
result = supabase.table("app_users").insert({"username": "kim", ...}).select("*").execute()
print(result.data)  # [{"id": "abc...", "username": "kim", ...}]
```

### Pydantic 모델 데이터를 딕셔너리로 변환

```python
from pydantic import BaseModel

class UserCreate(BaseModel):
    username: str
    display_name: str

data = UserCreate(username="kim", display_name="김학생")

# .model_dump()로 딕셔너리로 변환
payload = data.model_dump()  # {"username": "kim", "display_name": "김학생"}

result = supabase.table("app_users").insert(payload).select("*").execute()
```

## 7. FastAPI 엔드포인트 연결

이제 Supabase 쿼리를 FastAPI 엔드포인트 안에 넣습니다.

### 사용자 생성

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class UserCreate(BaseModel):
    username: str = Field(..., min_length=2, max_length=30)
    display_name: str = Field(..., min_length=1, max_length=50)


@app.post("/users", status_code=201)
def create_user(data: UserCreate):
    result = (
        supabase.table("app_users")
        .insert(data.model_dump())
        .select("*")
        .execute()
    )
    if not result.data:
        raise HTTPException(status_code=500, detail="저장에 실패했습니다")
    return result.data[0]
```

### 사용자 목록 조회

```python
@app.get("/users")
def list_users():
    result = (
        supabase.table("app_users")
        .select("*")
        .order("created_at", desc=True)
        .execute()
    )
    return result.data  # 빈 리스트여도 그냥 반환
```

### 대화방 메시지 조회

```python
@app.get("/conversations/{conversation_id}/messages")
def list_messages(conversation_id: str):
    result = (
        supabase.table("messages")
        .select("*")
        .eq("conversation_id", conversation_id)
        .order("created_at")  # 오래된 것부터 (기본 ASC)
        .execute()
    )
    return result.data
```

### 서버 실행


### Swagger UI 실습 (http://localhost:8000/docs)

1. `POST /users` → Body에 `{"username": "kim", "display_name": "김학생"}` → Execute → 201 응답의 `id` 복사
2. `POST /users` → Body에 `{"username": "lee", "display_name": "이학생"}` → Execute
3. `GET /users` → 2명 목록 확인
4. `POST /conversations` → Body에 `{"user_id": "복사한-UUID", "title": "첫 대화"}` → Execute → `id` 복사
5. `POST /conversations/{id}/messages` → Body에 `{"role": "user", "content": "안녕!"}` → Execute
6. `POST /conversations/{id}/messages` → Body에 `{"role": "assistant", "content": "안녕하세요!"}` → Execute
7. `GET /conversations/{id}/messages` → 메시지 2개 확인
8. Supabase Table Editor에서 저장된 데이터 직접 확인

## 10. 흔한 실수와 해결법

| 오류 | 원인 | 해결 |
|------|------|------|
| `KeyError: 'SUPABASE_URL'` | .env 파일 없거나 키 이름 오타 | .env.example 복사 후 값 입력 |
| `result.data`가 빈 리스트 (insert 후) | `.select("*")` 누락 | `.insert(payload).select("*").execute()` |
| `422 Unprocessable Entity` | Pydantic 검증 실패 | 요청 바디 필드 이름·형식 확인 |
| `postgrest APIError 23505` | UNIQUE 제약 위반 (username 중복) | 다른 username 사용 |
| `postgrest APIError 23503` | FK 위반 (없는 user_id 사용) | 먼저 사용자 생성 후 그 id 사용 |
| `postgrest APIError 23514` | CHECK 제약 위반 (role 오타) | `user`, `assistant`, `system` 중 하나 |
| `result.data` 인덱스 오류 | 빈 리스트에서 `[0]` 접근 | `if not result.data: raise HTTPException(404, ...)` |
| `.env` 로드 안 됨 | `load_dotenv()` 호출 누락 | 파일 맨 위에서 `load_dotenv()` 호출 |

## 핵심 패턴 요약

| 기능 | 코드 |
|------|------|
| 클라이언트 생성 | `create_client(URL, KEY)` |
| 전체 조회 | `.table("x").select("*").execute()` |
| 조건 조회 | `.eq("컬럼", 값)` |
| 정렬 | `.order("created_at", desc=True)` |
| 페이지네이션 | `.limit(10).offset(0)` |
| 저장 + 결과 반환 | `.insert(payload).select("*").execute()` |
| 결과 추출 | `result.data` |
| 첫 행 (없으면 404) | `if not result.data: raise HTTPException(404, ...)` |
