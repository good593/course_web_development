## 1. 생성형 AI 코드 생성이란?

Claude와 같은 대형 언어 모델(LLM)은 자연어 설명을 받아 **완성된 코드**를 생성할 수 있습니다.

```
개발자: "사용자 등록/조회/삭제 REST API를 FastAPI와 Pydantic으로 만들어줘"
    │
    ▼
Claude
    │
    ▼
완성된 FastAPI 코드 (main.py, models.py, schemas.py ...)
```

**활용 시나리오:**
- 반복적인 CRUD 엔드포인트 초안 생성
- Pydantic 모델 자동 설계
- 테스트 코드 골격 생성
- 기존 코드 리팩터링 제안

## 3. 기본 API 호출

```python
import anthropic
from dotenv import load_dotenv

load_dotenv()  # .env 파일에서 ANTHROPIC_API_KEY 로드

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "FastAPI로 Hello World 엔드포인트를 만드는 코드를 작성해줘."}
    ]
)

print(message.content[0].text)
```

### 응답 구조

```python
message.id           # 메시지 ID
message.model        # 사용된 모델
message.role         # "assistant"
message.content      # List[ContentBlock]
message.content[0].text  # 실제 텍스트
message.stop_reason  # "end_turn" | "max_tokens" | ...
message.usage.input_tokens   # 입력 토큰 수
message.usage.output_tokens  # 출력 토큰 수
```

## 4. 스트리밍 — 실시간 출력

코드 생성처럼 긴 응답은 스트리밍으로 수신해야 타임아웃을 방지하고 사용자 경험을 개선할 수 있습니다.

```python
import anthropic
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic()

prompt = """
FastAPI를 사용해서 다음 요구사항을 구현해줘:
- POST /users: 사용자 생성
- GET /users/{user_id}: 사용자 조회
- DELETE /users/{user_id}: 사용자 삭제
Pydantic으로 입출력을 검증하고, 인메모리 dict를 DB로 사용해줘.
"""

with client.messages.stream(
    model="claude-opus-4-8",
    max_tokens=4096,
    messages=[{"role": "user", "content": prompt}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)  # 실시간 출력

final_message = stream.get_final_message()
print(f"\n\n총 토큰: {final_message.usage.input_tokens + final_message.usage.output_tokens}")
```

## 5. 적응형 추론 (Adaptive Thinking)

복잡한 아키텍처 설계나 까다로운 검증 로직처럼 **깊은 추론이 필요한** 작업에는 `thinking` 옵션을 사용합니다.

```python
import anthropic
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic()

prompt = """
전자상거래 주문 API를 설계해줘.
요구사항:
1. 주문 생성 시 재고 확인 후 차감
2. 주문 상태 전이 규칙: pending → processing → shipped → delivered
3. 취소는 pending/processing 상태에서만 가능
4. 환불 금액 계산 (배송 중이면 배송비 공제)

FastAPI + Pydantic + 인메모리 DB로 구현하고,
모든 비즈니스 로직 검증을 포함해줘.
"""

with client.messages.stream(
    model="claude-opus-4-8",
    max_tokens=8192,
    thinking={"type": "adaptive"},  # 복잡한 문제에 추론 활성화
    messages=[{"role": "user", "content": prompt}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

> **adaptive thinking**: Claude가 문제 복잡도를 스스로 판단해 필요한 만큼 내부 추론(chain-of-thought)을 사용합니다. 단순한 질문에는 즉시 답하고, 복잡한 설계 문제에는 깊이 고민합니다.

## 6. 프롬프트 엔지니어링 — 좋은 코드를 얻는 법

### 나쁜 프롬프트 vs 좋은 프롬프트

**나쁜 예:**
```
FastAPI 코드 만들어줘
```

**좋은 예:**
```
FastAPI와 Pydantic v2를 사용해서 상품 관리 API를 만들어줘.

[요구사항]
- POST /products: 상품 생성
- GET /products: 상품 목록 조회 (페이지네이션: page, size 쿼리 파라미터)
- GET /products/{product_id}: 특정 상품 조회
- PATCH /products/{product_id}: 상품 부분 수정
- DELETE /products/{product_id}: 상품 삭제

[데이터 모델]
- Product: id(int), name(str, 2~100자), price(int, 1원 이상), stock(int, 0 이상), category(str)
- 입력 스키마(ProductCreate)와 응답 스키마(ProductResponse) 분리

[검증]
- 상품명 중복 불허 (409)
- 재고보다 많은 수량 주문 불허 (400)
- 존재하지 않는 상품 404 반환

[기타]
- 인메모리 dict 사용
- 모든 엔드포인트에 적절한 HTTP 상태 코드
- 한국어 주석 포함
```

### 프롬프트 체크리스트

- [ ] 사용할 프레임워크/라이브러리 명시
- [ ] 엔드포인트 목록과 HTTP 메서드 명시
- [ ] 데이터 모델 필드와 제약 조건 명시
- [ ] 에러 처리 요구사항 명시
- [ ] 코드 스타일/언어 명시 (한국어 주석, 타입 힌트 등)
- [ ] 사용 금지 항목 명시 (DB 없이 인메모리만 등)

## 7. FastAPI 코드 자동 생성기 만들기

```python
import anthropic
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic()

SYSTEM_PROMPT = """당신은 FastAPI 전문가입니다.
다음 규칙을 따라 코드를 생성하세요:
1. Python 타입 힌트를 반드시 사용하세요
2. Pydantic v2 BaseModel로 입출력 스키마를 분리하세요
3. HTTPException으로 적절한 에러를 반환하세요
4. 한국어 주석을 포함하세요
5. 마크다운 코드 블록(```python)으로 코드를 감싸세요
"""

def generate_api_code(requirements: str) -> str:
    """자연어 요구사항을 받아 FastAPI 코드를 생성합니다."""
    print("코드 생성 중...\n")

    with client.messages.stream(
        model="claude-opus-4-8",
        max_tokens=8192,
        thinking={"type": "adaptive"},
        system=SYSTEM_PROMPT,
        messages=[
            {"role": "user", "content": f"다음 API를 구현해줘:\n\n{requirements}"}
        ],
    ) as stream:
        result = []
        for text in stream.text_stream:
            print(text, end="", flush=True)
            result.append(text)

    return "".join(result)


def save_generated_code(content: str, filename: str = "generated_api.py"):
    """생성된 코드에서 Python 블록을 추출해 파일로 저장합니다."""
    import re
    pattern = r"```python\n(.*?)```"
    matches = re.findall(pattern, content, re.DOTALL)

    if matches:
        with open(filename, "w", encoding="utf-8") as f:
            f.write(matches[0])
        print(f"\n\n코드가 {filename}에 저장되었습니다.")
    else:
        print("\n\nPython 코드 블록을 찾지 못했습니다.")


if __name__ == "__main__":
    requirements = """
    블로그 게시글 API:
    - POST /posts: 게시글 작성 (title, content, author 필수)
    - GET /posts: 전체 목록 조회
    - GET /posts/{post_id}: 특정 게시글 조회
    - PUT /posts/{post_id}: 게시글 수정
    - DELETE /posts/{post_id}: 게시글 삭제

    Pydantic 스키마 분리, HTTPException 에러 처리 포함
    """

    generated = generate_api_code(requirements)
    save_generated_code(generated)
```

## 8. 다중 턴 대화로 반복 개선

```python
import anthropic
from dotenv import load_dotenv

load_dotenv()
client = anthropic.Anthropic()

conversation = []

def chat(user_message: str) -> str:
    conversation.append({"role": "user", "content": user_message})

    with client.messages.stream(
        model="claude-opus-4-8",
        max_tokens=4096,
        system="당신은 FastAPI 코드 생성 도우미입니다. 사용자의 피드백을 반영해 코드를 개선합니다.",
        messages=conversation,
    ) as stream:
        response_text = []
        for text in stream.text_stream:
            print(text, end="", flush=True)
            response_text.append(text)

    full_response = "".join(response_text)
    conversation.append({"role": "assistant", "content": full_response})
    print("\n")
    return full_response


# 1턴: 초안 생성
chat("사용자 CRUD API를 FastAPI로 만들어줘.")

# 2턴: 개선 요청
chat("비밀번호 해싱 기능을 추가하고, 응답에서 비밀번호 필드를 제거해줘.")

# 3턴: 추가 기능
chat("페이지네이션과 이메일로 사용자를 검색하는 기능도 추가해줘.")
```

## 10. 비용 관리

# 토큰 수 미리 확인 (API 호출 전)
token_count = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[{"role": "user", "content": prompt}],
)
print(f"예상 입력 토큰: {token_count.input_tokens}")

# 실제 사용량 확인 (API 호출 후)

```

### 모델별 특성

| 모델 | 용도 | 특징 |
|------|------|------|
| `claude-opus-4-8` | 복잡한 코드 설계, 아키텍처 | 최고 성능, adaptive thinking 지원 |
| `claude-sonnet-4-6` | 일반 코드 생성 | 빠른 속도, 균형 잡힌 성능 |
| `claude-haiku-4-5` | 간단한 코드 수정 | 가장 빠름, 저비용 |
