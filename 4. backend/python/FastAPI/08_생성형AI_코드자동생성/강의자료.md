## 1. 생성형 AI 코드 생성이란?

Ollama에서 실행하는 로컬 대형 언어 모델(LLM)은 자연어 설명을 받아 **완성된 코드 초안**을 생성할 수 있습니다.

```
개발자: "사용자 등록/조회/삭제 REST API를 FastAPI와 Pydantic으로 만들어줘"
    |
    v
Ollama + gemma4
    |
    v
완성된 FastAPI 코드 (main.py, models.py, schemas.py ...)
```

**활용 시나리오:**

- 반복적인 CRUD 엔드포인트 초안 생성
- Pydantic 모델 자동 설계
- 테스트 코드 골격 생성
- 기존 코드 리팩터링 제안

## 2. 환경 준비

### Ollama 설치

1. [ollama.com](https://ollama.com)에서 Ollama를 설치합니다.
2. 터미널에서 Ollama가 동작하는지 확인합니다.

```bash
ollama --version
```

### gemma4 모델 내려받기

```bash
ollama pull gemma4
```

또는 처음 실행과 동시에 내려받을 수 있습니다.

```bash
ollama run gemma4
```

> `gemma4`는 텍스트와 이미지 입력을 지원하는 Ollama 모델입니다. 기본 모델 외에도 `gemma4:e2b`, `gemma4:e4b`, `gemma4:12b`, `gemma4:26b`, `gemma4:31b` 같은 변형을 선택할 수 있습니다.

### Python 패키지 설치

```bash
pip install ollama
```

이번 예제는 로컬 Ollama 서버를 사용하므로 API 키와 `.env` 파일이 필요 없습니다.

## 3. 기본 API 호출

```python
from ollama import chat

response = chat(
    model="gemma4",
    messages=[
        {"role": "user", "content": "FastAPI로 Hello World 엔드포인트를 만드는 코드를 작성해줘."}
    ],
    options={
        "temperature": 1.0,
        "top_p": 0.95,
        "top_k": 64,
        "num_predict": 1024,
    },
)

print(response.message.content)
```

### 응답 구조

Ollama Python 패키지는 응답을 객체처럼 읽을 수 있습니다.

```python
response.model                 # 사용된 모델
response.message.role          # "assistant"
response.message.content       # 실제 텍스트
response.done                  # 생성 완료 여부
response.prompt_eval_count     # 입력 토큰 수 추정
response.eval_count            # 출력 토큰 수 추정
response.total_duration        # 전체 처리 시간(ns)
```

패키지 버전에 따라 일부 통계 필드는 없을 수 있습니다. 수업 코드에서는 `getattr()`로 안전하게 읽습니다.

## 4. 스트리밍 - 실시간 출력

코드 생성처럼 긴 응답은 스트리밍으로 수신하면 사용자가 결과를 기다리는 동안 진행 상황을 바로 확인할 수 있습니다.

```python
from ollama import chat

prompt = """
FastAPI를 사용해서 다음 요구사항을 구현해줘:
- POST /users: 사용자 생성
- GET /users/{user_id}: 사용자 조회
- DELETE /users/{user_id}: 사용자 삭제
Pydantic으로 입출력을 검증하고, 인메모리 dict를 DB로 사용해줘.
"""

stream = chat(
    model="gemma4",
    messages=[{"role": "user", "content": prompt}],
    stream=True,
    options={
        "temperature": 1.0,
        "top_p": 0.95,
        "top_k": 64,
        "num_predict": 4096,
    },
)

for chunk in stream:
    text = chunk.message.content or ""
    print(text, end="", flush=True)
```

## 5. gemma4 thinking 모드 활용

복잡한 아키텍처 설계나 까다로운 검증 로직처럼 깊은 추론이 필요한 작업에는 gemma4의 thinking 모드를 사용할 수 있습니다.

thinking 모드는 `system` 프롬프트 맨 앞에 `<|think|>` 토큰을 넣어 켭니다. 끄고 싶으면 이 토큰을 제거합니다.

```python
from ollama import chat

SYSTEM_PROMPT = """<|think|>
당신은 FastAPI 전문가입니다.
복잡한 요구사항을 단계적으로 검토한 뒤 실행 가능한 코드를 작성하세요.
"""

prompt = """
전자상거래 주문 API를 설계해줘.
요구사항:
1. 주문 생성 시 재고 확인 후 차감
2. 주문 상태 전이 규칙: pending -> processing -> shipped -> delivered
3. 취소는 pending/processing 상태에서만 가능
4. 환불 금액 계산 (배송 중이면 배송비 공제)

FastAPI + Pydantic + 인메모리 DB로 구현하고,
모든 비즈니스 로직 검증을 포함해줘.
"""

stream = chat(
    model="gemma4",
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": prompt},
    ],
    stream=True,
    options={
        "temperature": 1.0,
        "top_p": 0.95,
        "top_k": 64,
        "num_predict": 8192,
    },
)

for chunk in stream:
    print(chunk.message.content or "", end="", flush=True)
```

> 다중 턴 대화에서는 이전 assistant 응답을 다시 messages에 넣을 때 thinking 내용을 제외하고 최종 답변만 저장하는 것이 좋습니다.

## 6. 프롬프트 엔지니어링 - 좋은 코드를 얻는 법

### 나쁜 프롬프트 vs 좋은 프롬프트

**나쁜 예:**

```
FastAPI 코드 만들어줘
```

**좋은 예:**

```
FastAPI와 Pydantic v2를 사용해서 상품 관리 API를 만들어줘.

[요구사항]
- POST /products: 상품 생성
- GET /products: 상품 목록 조회 (페이지네이션: page, size 쿼리 파라미터)
- GET /products/{product_id}: 특정 상품 조회
- PATCH /products/{product_id}: 상품 부분 수정
- DELETE /products/{product_id}: 상품 삭제

[데이터 모델]
- Product: id(int), name(str, 2~100자), price(int, 1원 이상), stock(int, 0 이상), category(str)
- 입력 스키마(ProductCreate)와 응답 스키마(ProductResponse) 분리

[검증]
- 상품명 중복 불허 (409)
- 재고보다 많은 수량 주문 불허 (400)
- 존재하지 않는 상품 404 반환

[기타]
- 인메모리 dict 사용
- 모든 엔드포인트에 적절한 HTTP 상태 코드
- 한국어 주석 포함
```

### 프롬프트 체크리스트

- [ ] 사용할 프레임워크/라이브러리 명시
- [ ] 엔드포인트 목록과 HTTP 메서드 명시
- [ ] 데이터 모델 필드와 제약 조건 명시
- [ ] 에러 처리 요구사항 명시
- [ ] 코드 스타일/언어 명시 (한국어 주석, 타입 힌트 등)
- [ ] 사용 금지 항목 명시 (DB 없이 인메모리만 등)

## 7. FastAPI 코드 자동 생성기 만들기

```python
import re

from ollama import chat

MODEL = "gemma4"

OPTIONS = {
    "temperature": 1.0,
    "top_p": 0.95,
    "top_k": 64,
    "num_predict": 8192,
}

SYSTEM_PROMPT = """당신은 FastAPI 전문가입니다.
다음 규칙을 따라 코드를 생성하세요:
1. Python 타입 힌트를 반드시 사용하세요
2. Pydantic v2 BaseModel로 입출력 스키마를 분리하세요
3. HTTPException으로 적절한 에러를 반환하세요
4. 한국어 주석을 포함하세요
5. 마크다운 코드 블록(```python)으로 코드를 감싸세요
"""


def generate_api_code(requirements: str) -> str:
    """자연어 요구사항을 받아 FastAPI 코드를 생성합니다."""
    print("코드 생성 중...\n")

    stream = chat(
        model=MODEL,
        stream=True,
        options=OPTIONS,
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content": f"다음 API를 구현해줘:\n\n{requirements}"},
        ],
    )

    result = []
    for chunk in stream:
        text = chunk.message.content or ""
        print(text, end="", flush=True)
        result.append(text)

    return "".join(result)


def save_generated_code(content: str, filename: str = "generated_api.py"):
    """생성된 코드에서 Python 블록을 추출해 파일로 저장합니다."""
    pattern = r"```python\s*\n(.*?)```"
    matches = re.findall(pattern, content, re.DOTALL)

    if matches:
        with open(filename, "w", encoding="utf-8") as f:
            f.write(matches[0])
        print(f"\n\n코드가 {filename}에 저장되었습니다.")
    else:
        print("\n\nPython 코드 블록을 찾지 못했습니다.")


if __name__ == "__main__":
    requirements = """
    블로그 게시글 API:
    - POST /posts: 게시글 작성 (title, content, author 필수)
    - GET /posts: 전체 목록 조회
    - GET /posts/{post_id}: 특정 게시글 조회
    - PUT /posts/{post_id}: 게시글 수정
    - DELETE /posts/{post_id}: 게시글 삭제

    Pydantic 스키마 분리, HTTPException 에러 처리 포함
    """

    generated = generate_api_code(requirements)
    save_generated_code(generated)
```

## 8. 다중 턴 대화로 반복 개선

```python
from ollama import chat

MODEL = "gemma4"
OPTIONS = {
    "temperature": 1.0,
    "top_p": 0.95,
    "top_k": 64,
    "num_predict": 4096,
}

SYSTEM_PROMPT = "당신은 FastAPI 코드 생성 도우미입니다. 사용자의 피드백을 반영해 코드를 개선합니다."
conversation = []


def chat_with_model(user_message: str) -> str:
    conversation.append({"role": "user", "content": user_message})

    stream = chat(
        model=MODEL,
        stream=True,
        options=OPTIONS,
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            *conversation,
        ],
    )

    response_text = []
    for chunk in stream:
        text = chunk.message.content or ""
        print(text, end="", flush=True)
        response_text.append(text)

    full_response = "".join(response_text)
    conversation.append({"role": "assistant", "content": full_response})
    print("\n")
    return full_response


# 1턴: 초안 생성
chat_with_model("사용자 CRUD API를 FastAPI로 만들어줘.")

# 2턴: 개선 요청
chat_with_model("비밀번호 해싱 기능을 추가하고, 응답에서 비밀번호 필드를 제거해줘.")

# 3턴: 추가 기능
chat_with_model("페이지네이션과 이메일로 사용자를 검색하는 기능도 추가해줘.")
```

## 10. 로컬 실행 관리

Ollama는 로컬에서 모델을 실행하므로 API 호출 비용 대신 PC 자원 사용량이 중요합니다.

### 실행 전 확인

```bash
ollama list
ollama ps
```

- `ollama list`: 내려받은 모델 목록 확인
- `ollama ps`: 현재 메모리에 올라간 모델 확인

### 모델별 특성

| 모델 | 용도 | 특징 |
|------|------|------|
| `gemma4` | 기본 실습 | 기본 태그, 텍스트/이미지 입력 지원 |
| `gemma4:e2b` | 가벼운 로컬 실습 | 작은 edge 모델, 128K 컨텍스트 |
| `gemma4:e4b` | 균형형 로컬 실습 | 기본 `latest`와 같은 계열, 128K 컨텍스트 |
| `gemma4:12b` | 코드 생성 품질 강화 | 256K 컨텍스트 |
| `gemma4:26b` | 복잡한 설계/추론 | MoE 모델, 256K 컨텍스트 |
| `gemma4:31b` | 고성능 워크스테이션 | dense 모델, 256K 컨텍스트 |

> 모델 크기와 제공 여부는 바뀔 수 있으므로 실제 수업 전에는 [Ollama gemma4 모델 페이지](https://ollama.com/library/gemma4)를 확인하세요.

### 로컬 실행 통계 확인

비스트리밍 응답에서는 토큰 수와 처리 시간 같은 통계를 확인할 수 있습니다.

```python
from ollama import chat

response = chat(
    model="gemma4",
    messages=[{"role": "user", "content": "FastAPI 코드 생성 프롬프트 예시를 하나 만들어줘."}],
    options={
        "temperature": 1.0,
        "top_p": 0.95,
        "top_k": 64,
        "num_predict": 512,
    },
)

print(response.message.content)
print(f"입력 토큰 추정: {response.prompt_eval_count}")
print(f"출력 토큰 추정: {response.eval_count}")
print(f"총 소요 시간: {response.total_duration / 1_000_000_000:.2f}초")
```
