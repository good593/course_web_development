# 14교시: AI 기반 기능 확장

## 학습 목표

- 기존 CRUD API에 Claude를 활용한 AI 기능 추가
- 비동기(async) 엔드포인트로 LLM 호출 처리
- 스트리밍 응답으로 AI 생성 결과 실시간 전달
- Feature Request → 코드 자동 생성 파이프라인 구현

## 이번 교시의 범위

14교시는 **기존 CRUD API에 AI 기능을 붙이는 서비스 확장**에 집중합니다.

| 교시 | 핵심 역할 | 산출물 |
|------|-----------|--------|
| 8교시 | 자연어 요구사항 → FastAPI/Pydantic 코드 생성 | 코드 생성 프롬프트, 스트리밍 코드 생성기 |
| 14교시 | 이미 만든 CRUD 서비스에 AI 기능 추가 | 요약, 태그 추천, 리뷰, 스팸 감지 같은 AI 엔드포인트 |

코드 초안을 AI로 생성하는 방법은 8교시에서 다뤘으므로, 이번 교시는 AI 호출을 실제 API 기능으로 설계하고 운영 가능한 엔드포인트로 연결하는 데 초점을 둡니다.

## 2. 비동기 엔드포인트

### 동기 vs 비동기

```python
# 동기 — LLM 호출 중 다른 요청 처리 불가
@app.post("/posts/{post_id}/ai/summarize")
def summarize_post_sync(post_id: int):
    result = client.messages.create(...)   # 블로킹 — 평균 3~10초
    return result

# 비동기 — LLM 호출 중 다른 요청 동시 처리 가능
@app.post("/posts/{post_id}/ai/summarize")
async def summarize_post_async(post_id: int):
    result = await asyncio.to_thread(client.messages.create, ...)
    return result
```

### asyncio.to_thread 사용 이유

Anthropic Python SDK는 동기 클라이언트이므로, async 엔드포인트에서 직접 호출하면 이벤트 루프가 블로킹됩니다. `asyncio.to_thread()`로 별도 스레드에서 실행합니다.

```python
import asyncio
import anthropic

client = anthropic.Anthropic()  # 동기 클라이언트

async def call_claude(prompt: str) -> str:
    def _call():
        resp = client.messages.create(
            model="claude-opus-4-8",
            max_tokens=1024,
            thinking={"type": "adaptive"},
            messages=[{"role": "user", "content": prompt}],
        )
        return resp.content[-1].text   # thinking 블록 제외, 텍스트만

    return await asyncio.to_thread(_call)
```

## 3. 게시글 요약 자동 생성

### 엔드포인트 설계

```
POST /posts/{post_id}/ai/summarize
  → 게시글 내용을 Claude에게 전달
  → 2~3문장 요약 생성
  → Post.summary 필드에 저장 후 반환
```

### 구현

```python
@app.post("/posts/{post_id}/ai/summarize", response_model=PostResponse)
async def ai_summarize_post(post_id: int, db: Session = Depends(get_db)):
    post = get_post_or_404(db, post_id)

    prompt = f"""다음 블로그 게시글을 2~3문장으로 요약해줘.
요약문만 출력하고 다른 말은 하지 마.

제목: {post.title}
내용:
{post.content}"""

    summary = await call_claude(prompt)

    # DB에 요약 저장
    post.summary = summary.strip()
    db.commit()
    db.refresh(post)

    return post
```

## 4. 태그 자동 추천

### 구조화된 출력 받기

AI 출력을 JSON으로 받으면 파싱하기 쉽습니다.

```python
@app.post("/posts/{post_id}/ai/tags", response_model=TagSuggestionResponse)
async def ai_suggest_tags(post_id: int, db: Session = Depends(get_db)):
    post = get_post_or_404(db, post_id)

    prompt = f"""다음 블로그 게시글에 어울리는 태그를 5개 추천해줘.
반드시 아래 JSON 형식으로만 출력해:
{{"tags": ["태그1", "태그2", "태그3", "태그4", "태그5"]}}

제목: {post.title}
내용: {post.content[:1000]}"""

    raw = await call_claude(prompt)

    # JSON 파싱
    import json, re
    match = re.search(r'\{.*\}', raw, re.DOTALL)
    if not match:
        raise HTTPException(500, "AI 응답을 파싱할 수 없습니다")

    data = json.loads(match.group())
    return TagSuggestionResponse(post_id=post_id, tags=data.get("tags", []))
```

## 6. 스트리밍 응답 (SSE)

긴 AI 응답을 생성 즉시 클라이언트에 전달합니다.

```python
from fastapi.responses import StreamingResponse

@app.post("/posts/{post_id}/ai/analyze/stream")
async def ai_analyze_stream(post_id: int, db: Session = Depends(get_db)):
    post = get_post_or_404(db, post_id)

    async def event_stream():
        def _stream():
            with client.messages.stream(
                model="claude-opus-4-8",
                max_tokens=2048,
                messages=[{
                    "role": "user",
                    "content": f"다음 블로그 게시글을 분석해줘:\n\n{post.title}\n\n{post.content}"
                }],
            ) as stream:
                for text in stream.text_stream:
                    yield text

        loop = asyncio.get_event_loop()
        queue = asyncio.Queue()

        def producer():
            try:
                for chunk in _stream():
                    asyncio.run_coroutine_threadsafe(queue.put(("data", chunk)), loop)
            except Exception as e:
                asyncio.run_coroutine_threadsafe(
                    queue.put(("error", f"스트리밍 오류: {type(e).__name__}")),
                    loop,
                )
            finally:
                asyncio.run_coroutine_threadsafe(queue.put(("done", None)), loop)

        import threading
        thread = threading.Thread(target=producer, daemon=True)
        thread.start()

        while True:
            kind, chunk = await queue.get()
            if kind == "done":
                break
            if kind == "error":
                yield f"event: error\ndata: {chunk}\n\n"
                continue
            yield f"data: {chunk}\n\n"

    return StreamingResponse(event_stream(), media_type="text/event-stream")
```

## 7. Feature Request → 코드 자동 생성

기존 API 코드를 참고해 새 기능을 자동으로 추가합니다.

```python
@app.post("/ai/generate-feature", response_model=FeatureCodeResponse)
async def ai_generate_feature(request: FeatureRequest):
    """
    요청 예시:
    {
      "feature": "게시글 좋아요(likes) 기능 추가",
      "context": "현재 Post 모델에 likes 필드 없음, SQLAlchemy 사용 중"
    }
    """
    with open("main.py", encoding="utf-8") as f:
        current_code = f.read()

    prompt = f"""현재 FastAPI 블로그 API 코드를 참고해서 새 기능을 구현해줘.

[새 기능 요청]
{request.feature}

[추가 컨텍스트]
{request.context}

[현재 코드 구조 요약]
{current_code[:3000]}

[출력 형식]
1. models.py 추가/수정 코드
2. schemas.py 추가 코드
3. main.py 추가 엔드포인트 코드
각 파일 코드를 ```python ... ``` 블록으로 구분해서 작성해줘."""

    generated = await call_claude(prompt, max_tokens=4096)
    return FeatureCodeResponse(
        feature=request.feature,
        generated_code=generated,
    )
```

## 8. AI 기능 설계 시 주의사항

### 비용과 속도 고려

```python
# 긴 컨텍스트는 비용 증가 → 필요한 부분만 전달
content_for_ai = post.content[:2000]  # 최대 2000자로 제한

# 단순 분류 작업은 thinking 비활성화
result = await call_claude(prompt, use_thinking=False)  # 빠르고 저렴
```

### 에러 처리

```python
async def call_claude(prompt: str, ...) -> str:
    try:
        return await asyncio.to_thread(_call)
    except anthropic.APIStatusError as e:
        raise HTTPException(503, f"AI 서비스 오류: {e.message}")
    except anthropic.APITimeoutError:
        raise HTTPException(504, "AI 응답 시간 초과")
```
