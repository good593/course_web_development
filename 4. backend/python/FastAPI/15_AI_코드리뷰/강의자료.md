# 15교시: AI 기반 코드 리뷰

## 학습 목표

- Claude를 활용한 자동화된 코드 리뷰 파이프라인 구현
- 보안 취약점, 성능 이슈, 코드 품질을 카테고리별로 분석
- 다중 파일 리뷰와 변경사항(diff) 기반 리뷰 구현
- CI/CD 연동 시나리오 이해

## 1. AI 코드 리뷰의 가치

### 사람 리뷰 vs AI 리뷰

| 항목 | 사람 리뷰 | AI 리뷰 |
|------|----------|---------|
| 속도 | 수 시간~일 | 수십 초 |
| 일관성 | 컨디션에 따라 다름 | 항상 동일 기준 |
| 범위 | 리뷰어 경험 의존 | 보안, 성능, 스타일 동시 |
| 문맥 이해 | 높음 | 높음 (Claude 기준) |
| 비즈니스 도메인 | 높음 | 낮음 |

**활용 전략**: AI 리뷰로 기본 이슈를 빠르게 잡고, 사람 리뷰는 비즈니스 로직과 아키텍처 결정에 집중.

```

## 3. 기본 파일 리뷰

### 단일 파일 리뷰

```python
async def review_file(file_path: str, focus: list[str] = None) -> ReviewResult:
    code = Path(file_path).read_text(encoding="utf-8")
    focus_str = ", ".join(focus) if focus else "보안, 성능, 아키텍처, 가독성"

    prompt = f"""다음 Python 코드를 [{focus_str}] 관점에서 리뷰해줘.

반드시 아래 JSON 형식으로만 출력해:
{{
  "summary": "전반적인 코드 품질 한 줄 요약",
  "score": 1~10,
  "issues": [
    {{
      "category": "security|performance|architecture|readability",
      "severity": "critical|warning|info",
      "line": 줄번호 또는 null,
      "description": "이슈 설명",
      "suggestion": "개선 방법"
    }}
  ],
  "positives": ["잘된 점1", "잘된 점2"]
}}

[코드: {file_path}]
```python
{code[:4000]}
```"""

    raw = await call_claude(prompt, max_tokens=4096)
    return parse_review_result(raw)
```

### 심각도 분류

| 심각도 | 예시 | 처리 |
|--------|------|------|
| `critical` | SQL Injection, 인증 누락 | 즉시 수정 필요 |
| `warning` | N+1 쿼리, 예외 처리 누락 | 수정 권장 |
| `info` | 네이밍 개선, 주석 추가 | 선택적 개선 |

## 4. 다중 파일 리뷰

여러 파일을 묶어 전체적인 아키텍처와 일관성을 검토합니다.

```python
async def review_project(file_paths: list[str]) -> ProjectReviewResult:
    files_content = []
    for path in file_paths:
        if Path(path).exists():
            code = Path(path).read_text(encoding="utf-8")
            files_content.append(f"=== {path} ===\n{code[:2000]}")

    combined = "\n\n".join(files_content)

    prompt = f"""다음 FastAPI 프로젝트의 여러 파일을 종합적으로 리뷰해줘.

[검토 관점]
1. 파일 간 의존성 방향이 올바른가 (Repository ← Service ← Router)
2. 스키마 일관성 (Create/Update/Response 분리 여부)
3. 에러 처리 일관성
4. 중복 코드 존재 여부
5. 보안 취약점

JSON 형식으로 출력해줘:
{{
  "architecture_score": 1~10,
  "consistency_issues": ["이슈1", ...],
  "security_issues": ["이슈1", ...],
  "duplicate_code": ["중복 패턴1", ...],
  "recommendations": ["개선 제안1", ...]
}}

[프로젝트 파일들]
{combined}"""

    raw = await call_claude(prompt, max_tokens=4096)
    return parse_project_review(raw)
```

## 5. Diff 기반 리뷰 (PR 리뷰)

변경된 코드만 리뷰해 효율을 높입니다.

```python
import subprocess

def get_git_diff(base_branch: str = "main") -> str:
    result = subprocess.run(
        ["git", "diff", f"{base_branch}...HEAD", "--", "*.py"],
        capture_output=True,
        text=True,
    )
    return result.stdout

async def review_pr_diff(diff: str) -> PRReviewResult:
    if not diff.strip():
        return PRReviewResult(message="변경된 Python 파일이 없습니다.")

    prompt = f"""다음 Git diff를 PR 리뷰 관점에서 검토해줘.
추가된 코드(+)를 중심으로 분석하되, 제거된 코드(-)의 맥락도 참고해.

[검토 항목]
- 새로운 보안 취약점 도입 여부
- 성능 저하 가능성
- 기존 코드와의 일관성
- 테스트 필요 여부

JSON 형식으로 출력해:
{{
  "approve": true/false,
  "summary": "변경사항 요약",
  "issues": [{{"severity": "...", "description": "...", "line_hint": "..."}}],
  "test_suggestions": ["테스트케이스 제안1", ...]
}}

[Git Diff]
{diff[:5000]}"""

    raw = await call_claude(prompt, max_tokens=2048)
    return parse_pr_review(raw)
```

## 6. 리뷰 결과 리포트 생성

```python
async def generate_review_report(review: ReviewResult, output_path: str = "REVIEW.md"):
    """리뷰 결과를 마크다운 리포트로 저장."""
    prompt = f"""다음 코드 리뷰 결과를 보기 좋은 마크다운 리포트로 작성해줘.
심각도별 이슈 목록, 코드 개선 예시, 체크리스트 형식으로 정리해.

[리뷰 결과]
{json.dumps(review.model_dump(), ensure_ascii=False, indent=2)}"""

    report = await call_claude(prompt, max_tokens=4096)
    Path(output_path).write_text(report, encoding="utf-8")
    return report
```

## 7. CLI 자동화 도구

```bash
# 단일 파일 리뷰
python main.py review main.py

# 프로젝트 전체 리뷰
python main.py project main.py models.py schemas.py

# PR diff 리뷰 (현재 브랜치 vs main)
python main.py pr

# 특정 카테고리만 리뷰
python main.py review main.py --focus security,performance

# 리포트 파일로 저장
python main.py review main.py --output REVIEW.md
```

### CLI 구현 구조

```python
if __name__ == "__main__":
    import sys
    command = sys.argv[1] if len(sys.argv) > 1 else "help"

    if command == "review":
        file_path = sys.argv[2]
        asyncio.run(cli_review_file(file_path))

    elif command == "project":
        files = sys.argv[2:]
        asyncio.run(cli_review_project(files))

    elif command == "pr":
        base = sys.argv[2] if len(sys.argv) > 2 else "main"
        asyncio.run(cli_review_pr(base))
```

## 9. CI/CD 연동 시나리오

### GitHub Actions 예시

```yaml
# .github/workflows/ai-review.yml
name: AI Code Review
on: [pull_request]

jobs:
  ai-review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: pip install anthropic python-dotenv

      - name: Run AI Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          git diff origin/main...HEAD -- '*.py' > changes.diff
          python 15_AI_코드리뷰/main.py pr-file changes.diff > review.md

      - name: Post Review Comment
        uses: actions/github-script@v6
        with:
          script: |
            const fs = require('fs');
            const review = fs.readFileSync('review.md', 'utf8');
            github.rest.issues.createComment({
              ...context.repo,
              issue_number: context.payload.pull_request.number,
              body: `## 🤖 AI 코드 리뷰\n\n${review}`
            });
```
