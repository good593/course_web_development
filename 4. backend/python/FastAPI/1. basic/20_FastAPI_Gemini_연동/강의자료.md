## 1. Gemini SDK 비동기 호출

### 동기 vs 비동기

FastAPI는 기본적으로 비동기(async) 기반입니다. Gemini SDK는 동기와 비동기 두 방식을 모두 지원합니다.

```python
# 동기 (sync) — FastAPI에서 사용 시 이벤트 루프 블로킹 위험
response = client.models.generate_content(...)

# 비동기 (async) — FastAPI async 엔드포인트에서 권장
response = await client.aio.models.generate_content(...)
```

### 비동기 클라이언트

```python
from google import genai

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

# client.aio 는 비동기 인터페이스
# - client.aio.models.generate_content()
# - client.aio.models.generate_content_stream()
# - client.aio.chats.create()
```

## 2. 단순 Q&A 엔드포인트

```python
from fastapi import FastAPI
from pydantic import BaseModel
from google import genai
from google.genai import types

app = FastAPI()
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

class AskRequest(BaseModel):
    question: str
    temperature: float = 0.7
    max_tokens: int = 500

class AskResponse(BaseModel):
    answer: str
    input_tokens: int
    output_tokens: int

@app.post("/ask", response_model=AskResponse)
async def ask(req: AskRequest):
    response = await client.aio.models.generate_content(
        model="gemini-3.5-flash",
        contents=req.question,
        config=types.GenerateContentConfig(
            temperature=req.temperature,
            max_output_tokens=req.max_tokens,
        ),
    )
    usage = response.usage_metadata
    return AskResponse(
        answer=response.text,
        input_tokens=usage.prompt_token_count,
        output_tokens=usage.candidates_token_count,
    )
```

## 3. 대화 세션 관리

사용자별 Chat 세션을 서버에서 관리합니다.

```python
from uuid import uuid4

# 메모리 내 세션 저장소
sessions: dict[str, object] = {}

def get_or_create_session(session_id: str) -> object:
    if session_id not in sessions:
        sessions[session_id] = client.chats.create(
            model="gemini-3.5-flash",
            config=types.GenerateContentConfig(
                system_instruction="친절한 AI 어시스턴트입니다.",
            ),
        )
    return sessions[session_id]

@app.post("/chat/{session_id}")
async def chat(session_id: str, req: ChatRequest):
    chat_session = get_or_create_session(session_id)
    # 동기 Chat API를 asyncio.to_thread로 비동기화
    response = await asyncio.to_thread(
        chat_session.send_message, req.message
    )
    return {"reply": response.text}
```

> Chat 세션(`client.chats`)은 비동기 버전(`client.aio.chats`)도 있습니다.

## 4. SSE 스트리밍 응답

긴 응답을 실시간으로 클라이언트에 전달합니다.

```python
from fastapi.responses import StreamingResponse
import asyncio

@app.post("/ask/stream")
async def ask_stream(req: AskRequest):
    async def event_generator():
        async for chunk in await client.aio.models.generate_content_stream(
            model="gemini-3.5-flash",
            contents=req.question,
            config=types.GenerateContentConfig(
                max_output_tokens=req.max_tokens,
            ),
        ):
            if chunk.text:
                yield f"data: {chunk.text}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
    )
```

### 클라이언트 측 (JavaScript)

```javascript
const source = new EventSource('/ask/stream');

source.onmessage = (event) => {
  if (event.data === '[DONE]') {
    source.close();
    return;
  }
  document.getElementById('output').textContent += event.data;
};
```

## 5. 전체 API 설계

```

POST /ask/stream           — 스트리밍 단순 질문
POST /chat/{session_id}/stream   — 스트리밍 세션 대화
GET  /stats                — 토큰 사용량 통계
```

## 6. 토큰 사용량 추적

```python
from dataclasses import dataclass, field

@dataclass
class UsageStats:
    total_requests: int = 0
    total_input_tokens: int = 0
    total_output_tokens: int = 0

    def add(self, input_tokens: int, output_tokens: int):
        self.total_requests += 1
        self.total_input_tokens += input_tokens
        self.total_output_tokens += output_tokens

    def estimated_cost_usd(self) -> float:
        # Gemini 3.5 Flash 표준 유료 단가 기준
        return (
            self.total_input_tokens  / 1_000_000 * 1.50 +
            self.total_output_tokens / 1_000_000 * 9.00
        )

stats = UsageStats()

# 엔드포인트에서 사용
@app.post("/ask")
async def ask(req: AskRequest):
    response = await client.aio.models.generate_content(...)
    usage = response.usage_metadata
    stats.add(usage.prompt_token_count, usage.candidates_token_count)
    ...
```

## 7. 에러 처리 미들웨어

```python
from fastapi import Request
from fastapi.responses import JSONResponse
from google.genai import errors

@app.exception_handler(errors.APIError)
async def gemini_error_handler(request: Request, exc: errors.APIError):
    status_map = {429: 429, 403: 401, 400: 400}
    status_code = status_map.get(exc.status_code, 502)
    return JSONResponse(
        status_code=status_code,
        content={"detail": f"Gemini API 에러: {exc.message}"},
    )
```

## 8. 세션 만료 처리

메모리 무한 증가를 막기 위해 오래된 세션을 정리합니다.

```python
import time

session_timestamps: dict[str, float] = {}
SESSION_TTL = 3600  # 1시간

def cleanup_old_sessions():
    now = time.time()
    expired = [
        sid for sid, ts in session_timestamps.items()
        if now - ts > SESSION_TTL
    ]
    for sid in expired:
        sessions.pop(sid, None)
        session_timestamps.pop(sid, None)
```
